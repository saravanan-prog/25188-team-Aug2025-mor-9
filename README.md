React Components
=================

     => React Components are like small building blocks of your UI.
     => Each part of a webpage (button, header, form, card, navbar) can be a component.

            They make your code:

                 - Reusable

                 - Organized

                 -  Easy to maintain

            Think of components like Lego pieces.
            You build a big app using many small pieces.



Types of React Components
=========================
      There are 2 types:

            1️⃣ Function Components (MOST COMMON)
                   
                   function Welcome() {
                        return <h1>Hello from a component!</h1>;
                  }
            

            2️⃣ Class Components (OLD STYLE — not recommended now)

                  class Welcome extends React.Component {
                        render() {
                        return <h1>Hello!</h1>;
                        }
                  }
